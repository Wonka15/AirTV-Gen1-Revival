# AirTV Gen1 Revival

Research into the original first-generation AirTV Player. This repository includes a GitHub Pages research site.

- **Website:** https://wonka15.github.io/AirTV-Gen1-Revival/
- **Official product page:** https://www.airtv.net/products/airtv_player/

## Project status

Early research. Board photos show a UART-marked area and PCB identifiers, but UART pinout and electrical levels are not confirmed. No custom firmware or alternative OS is claimed to work.

## Website

The site is a static HTML/CSS project in `index.html` and `assets/style.css`. It is designed for GitHub Pages from the `main` branch root.

## Research standards

Distinguish official specifications, third-party reports, direct observations, and hypotheses. Do not publish proprietary firmware, vendor keys, credentials, or copyrighted Sling/AirTV assets. Never connect to unknown board pads or flash firmware without verifying electrical levels and recovery procedures.
