Over-the-air television

Inside the box

  • SoCMarvell Armada 1500 Ultra BG4CT
  • CPUQuad-core ARM Cortex-A53 · reported 1.2 GHz
  • GPUVivante GC7000XS
  • SoftwareAndroid TV · version needs verification

These chip and software details come from secondary references. The markings on this specific board have not yet confirmed them. One retailer-style specification listing labels the processor “Single Core,” which conflicts with multiple device references and a launch-era hardware review reporting a quad-core Marvell SoC. We record that as a source discrepancy, not as a confirmed single-core CPU.

STATUS · IDEA
Why not SteamOS?

SteamOS is primarily built for x86-64 AMD systems. This device is reported to be ARM-based, so a native SteamOS installation is not a realistic first target. A game-streaming client is a more plausible experiment, but still untested.
